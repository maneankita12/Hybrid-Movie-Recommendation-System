# Hybrid Movie Recommendation System

An intelligent movie recommendation system combining Collaborative Filtering, Content-Based filtering, and Contextual AI.

## Features
- Search 9,700+ movies from MovieLens dataset
- Search ANY movie via TMDB API integration
- Personalized recommendations based on your ratings
- Hybrid ML approach (SVD + Content + Context)

## How to Use
1. Select "Similar Movies" mode
2. Enter any movie title (e.g., "Oppenheimer", "Toy Story")
3. Get personalized recommendations!

## Tech Stack
- Python 3.9
- Streamlit
- Scikit-learn
- Scikit-surprise (SVD)
- TMDB API
